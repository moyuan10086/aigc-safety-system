# Map data

`world.json` is the world GeoJSON test asset from the Apache ECharts repository:

https://github.com/apache/echarts/blob/master/test/data/map/json/world.json

Apache ECharts is licensed under Apache-2.0. The map is used only as a neutral
visual backdrop; source IP nodes are rendered as a non-geographic topology so
the dashboard does not claim location data it does not have.
