# AIGC 安全运营台目标与验收审计

日期：2026-08-05

唯一任务基线：飞书《AIGC 安全运营台｜比赛交付总手册》

## 结论

系统定位不是单一 AIGC 生成检测器，而是“真实性鉴别 + 内容安全审核”双主线安全运营台：既判断 Deepfake、AI 生成与来源凭证，也审核成人、武器、暴力、涉政、营销违规、违法活动、自伤、未成年人和个人敏感信息风险。系统已具备比赛演示主链、真实模型护栏、图片与非身份化人脸审核、红线知识与主动扫描、Agent 工具安全、C2PA、日志取证、驾驶舱和开放 API。当前不能宣称“全部完成”，因为真人试标仍为 `0/20`、`0/200`，专用 Ascend 护栏未部署，人工写入类截图尚缺，水印能力只有调研与边界设计。

## 不可回退边界

- 原始提示词和危险模型输出必须保留，但只进入 AES-GCM 加密证据库。
- 飞书、普通日志、驾驶舱、CSV 和公共 API 不得暴露危险原文、密码、API Key 或模型密钥。
- 人脸能力保持非身份化，不做人名识别、1:N 搜索、跨请求跟踪或 embedding 持久化。
- C2PA `confirmed_source` 不等于 AI 生成；`not_found` 不等于非 AI；未签名 marker 不建立信任。
- 人工标签只能由真实审核员完成，不代领、代看证据或代提交。
- 不停止 GPU/NPU 现有任务、不抢占卡位；通用 Qwen3 分类实验不得描述为 Qwen3Guard。
