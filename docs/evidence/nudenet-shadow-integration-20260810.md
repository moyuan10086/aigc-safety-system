# NudeNet 成人内容专用检测接入记录

日期：2026-08-10

## 接入结论

- NudeNet 3.4.2 / 320n 已作为本地成人内容专用检测器接入图片内容安全链路。
- 只识别明确裸露区域，不替代多模态模型对政治、暴力、武器、营销、隐私等类别的审核。
- 当前固定为影子证据：结果会展示和留存，但不改变多模态模型给出的最终处置。
- 图片以字节流送入本地 ONNX Runtime，不上传到第三方，也不在该适配器中保存副本。
- 模型采用 AGPL-3.0 许可证；平台界面和 API 结果均保留版本、许可证及源码链接。

## 边界与后续标定

- NudeNet 分数是检测器区域置信分，不是平台在真实业务分布上的统计准确率。
- UnsafeBench 仓库元数据可访问，但行级数据接口需要认证；当前未绕过权限下载，不能据此报告召回率或 F1。
- 在取得合规数据访问权后，应按独立测试集报告每类 Precision、Recall、F1、95% 置信区间和阈值曲线，再决定是否退出影子模式。
