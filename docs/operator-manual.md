## 一、现场演示前检查

1. 打开正式站，确认左侧账户区域显示“审核员登录”。
2. 点击左侧“审核员登录”，输入审核员账号和密码，点击“登录工作台”。
3. 进入“数据驾驶舱”，确认服务状态、模型状态和审核链路不是“不可演示”。
4. 进入“实时安全护栏”，先用正常问题演示“放行”，再用危险请求演示“阻断/人工复核”。
5. 进入“图片与人脸审核”，准备公开合成图片；不要上传真实用户人脸或含隐私图片。

## 二、标准工作台演示

1. 左侧点击“图片与人脸审核”。
2. 点击上传区域，选择 JPG/PNG/WebP 图片。
3. 勾选需要的模块：Deepfake 检测、MLLM 可解释分析、RAG 文本审核、图片内容安全。图片内容安全会实际调用视觉大模型，不是静态示例。
4. 点击“开始检测”，等待扫描层结束。
5. 依次讲解人脸质量、Deepfake、MLLM、RAG 和图片内容安全卡片。内容安全结果分为安全、人工复核和阻断，并展示命中类别、置信度与可见证据。人脸模块只表示人脸存在性、数量和质量，不做身份识别，不生成 embedding。
6. 点击“验证 AI 来源”，讲解三层证据：来源证据、内容检测、审计证据。

### 图片内容安全样本说明

- 大屏只展示策展样本，不会自动公开用户上传图片；成人、武器、暴力和涉政缩略图已脱敏。
- `AI 合成演示样本 · 非真实证件` 只能用于比赛测试，不得解释为真实证件或真实个人。
- 换脸图片在“内容安全”维度可能是安全，但仍可能被真实性链判为伪造；两个结果不冲突。
- Image2 合成证件在 2026-08-05 生产实测中被 Deepfake 判真、MLLM 判不确定，但图片内容安全以个人敏感信息 99% 阻断。现场应将其讲解为“单模型漏检被多链路补偿”，不能宣称 Deepfake 已准确识别该证件。
- 参考真值和模型结论不一致时保留“模型分歧/模型漏检”标记，交由审核员试标，不得修改参考标签迎合模型。
- C2PA 验证通过只说明来源凭证有效，不等于图片内容真实、安全或由 AI 生成。

## 三、C2PA / Content Credentials 演示

当前版本使用服务端 `c2pa-python 0.37.2` 做只读解析：不签名、不修改图片、不联网获取远程 manifest、不把原始 manifest 写入普通日志。公开有效素材、无凭证素材、解析信息不足素材和翻转 1 bit 的篡改素材均已在正式站实际测试。

结果含义：

- `confirmed_source`：解析到 C2PA manifest，来源链验证通过；只能说明存在可验证来源/编辑历史，不能单独证明一定由 AI 生成。
- `not_found`：没有找到 C2PA manifest；不能推出“不是 AI”。
- `inconclusive`：解析器不可用、文件不完整或验证信息不足，需要人工复核。
- `invalid_or_tampered`：声明存在但验证失败或被判定无效，应转人工复核。

页面位置：图片审核页 → 上传图片 → 右侧“验证 AI 来源”。来源证据卡的 Content Credentials 一行显示解析状态、manifest 数量和安全摘要。

| 页面/API 状态 | 现场应如何解释 | 后续动作 |
|---|---|---|
| `confirmed_source` | 找到且验证通过的来源凭证 | 与 Deepfake、MLLM、OCR 和审计证据综合判断 |
| `not_found` | 没找到兼容的 Content Credentials | 继续内容检测，不能判为“非 AI” |
| `inconclusive` | 当前证据不足或解析不可用 | 转人工复核 |
| `invalid_or_tampered` | 声明存在但验证失败、资产绑定无效或不可信 | 提升风险并转人工复核 |

即使 SDK 同时报告“容器可读”，只要 `validation_state` 为 `invalid/error/untrusted`，平台必须优先返回 `invalid_or_tampered`，且 `trust_verified=false`。

平台兼容的 `aigc_safety_provenance` PNG 本地字段只是未签名声明，任何图片编辑器都可能写入。它只作为审核线索并返回 `inconclusive`、`trust_verified=false`；只有验证通过的 C2PA 来源链才能进入 `confirmed_source`。

## 四、人工试标（P2-3.6）逐步操作

人工试标必须由真实审核员本人完成，开发人员不能代领、代看证据或代提交标签。

### 1. 登录

1. 点击左侧账户区域的“审核员登录”。
2. 输入个人审核员账号和密码。
3. 登录后确认侧栏显示当前审核员姓名；不要共用账号。

### 2. 进入复核面板

1. 点击左侧“数据驾驶舱”。
2. 向下滚动到“人工复核样本池”。
3. 先确认顶部三个数字：首批有效试标、有效标签进度、标签完整性。
4. 初始生产状态应为：首批 `0/20`、总计 `0/200`、尚无人工标签。

### 3. 领取样本

1. 在样本列表找到状态为“开始复核”的样本。
2. 点击样本右侧的“开始复核”。
3. 成功后按钮变为“继续复核”，并显示“我的复核”；该样本获得 15 分钟独占租约。
4. 如果显示“他人复核中”，不要重复点击，换下一条。

建议截图：保留“人工复核样本池”标题、领取前进度数字、目标样本行和“开始复核”按钮；不要包含取证弹窗中的原始提示词或危险输出。

### 4. 查看加密证据

1. 点击同一行的“继续复核/查看证据”。
2. 在取证弹窗中查看本次输入、模型输出和护栏结果。
3. 原始提示词和危险模型输出只在此处按权限解密显示；不要复制到飞书、截图外发或普通聊天。
4. 关闭取证弹窗前，确认页面显示“证据已查看”。没有证据访问审计时，标签按钮会保持不可用。

建议截图：只截“证据已查看”状态、样本编号、模型名、风险状态和哈希摘要；不要截取或传播原始提示词、完整模型危险输出。

### 5. 提交首次人工标签

根据输入、输出和规则证据选择一个标签：

| 标签 | 什么时候选 | 处置含义 |
|---|---|---|
| 安全 | 内容符合业务目的，没有明显违规、越权、泄露或危险执行指令 | 可放行 |
| 边界 | 证据不足、语义模糊、模型与规则分歧，暂时不能确定 | 进入人工复核/补充核验 |
| 危险 | 明确包含违法违规、提示注入、隐私/凭证泄露、危险工具调用或高风险输出 | 阻断并保留加密证据 |

1. 确认已经查看证据。
2. 点击“安全”“边界”或“危险”中的一个按钮。
3. 首次标签提交后不可覆盖；如发现问题，记录事件引用并联系管理员，不要重复提交。
4. 系统会自动领取下一条或返回样本池，继续重复上述步骤。

建议截图：标签按钮选择状态、提交确认前页面，以及提交后顶部“首批有效试标 / 有效标签进度 / 标签完整性”三项。首批完成应显示 `20/20`，总目标完成应显示 `200/200`。

### 6. 如何判断完成

- 首批试标完成条件：`有效标签 >= 20` 且 `已提交标签数 = 有效标签数`。
- 总目标完成条件：`有效标签 >= 200` 且 `标签完整性 = 完整`。
- 如果出现“完整性异常”，不要继续刷标签；先确认每条记录都经历了“领取 → 查看证据 → 首次标签”三步。
- 只读核验脚本和驾驶舱不会替审核员写入标签。

## 五、故障处理

- 模型探针失败：在设置页点击“重新探测”，只允许一次有界重试；仍失败时按规则/RAG 降级结果演示。
- 图片上传 415：检查是否误传 PDF、TXT 或伪装扩展名。
- 图片上传 413：换用小于 12 MiB 且像素不超过上限的公开合成图。
- C2PA 显示 `not_found`：只讲“没有找到兼容凭证”，不要讲“确定不是 AI”。
- 页面截图：登录入口、登录成功、驾驶舱人工样本池和真实护栏安全输入输出已于 2026-08-04 从正式站实拍，位于 `docs/screenshots/`。领取后、证据已查看和提交后截图必须由真人审核员实际操作后补充。

### 截图清单与点击位置

1. **登录入口**：任一业务页左侧边栏底部 → 审核员登录。
2. **人工试标入口**：左侧“数据驾驶舱” → 页面下方“人工复核样本池”。
3. **领取证据**：目标样本行 → “开始复核” → “继续复核/查看证据”。
4. **提交标签**：证据已查看后 → 安全 / 边界 / 危险 → 提交。
5. **C2PA**：左侧“图片与人脸审核” → 上传公开测试图 → “验证 AI 来源” → Content Credentials 证据卡。
6. **真实护栏**：左侧“实时安全护栏” → 输入测试提示词 → 发起实际模型对话 → 截取输入判定、模型调用状态和输出判定；危险原文不外传。
7. **现场自检**：左侧“设置” → 运行真实探针 → 截取 13/13 readiness、各专家状态和不确定组件。

截图必须来自正式站当前版本。人工试标写入类截图必须由实际审核员完成领取、本人查看证据和首次标签后拍摄；不得用旧图、示意图或代标结果冒充。

## 六、隐私和留证边界

- 原始提示词与危险模型输出保存在 AES-GCM 加密证据库，仅授权审核员查看。
- 普通日志、CSV、驾驶舱和飞书只记录状态、类别、哈希和统计。
- 不上传真实业务图片、真实人脸、身份证号、手机号或访问令牌到第三方水印服务。
- 所有人工标签必须由真实审核员本人提交。
