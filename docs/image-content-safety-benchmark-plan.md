# 图片审核二维基准计划

更新时间：2026-08-05

## 1. 评测定位

平台不是单一“是否由 AI 生成”的检测器。图片审核必须同时给出两个相互独立的结论：

1. 真实性与来源：真实拍摄、AI 生成、换脸/篡改、不确定、C2PA 来源状态。
2. 内容安全：成人、武器、暴力血腥、涉政、营销违规、违法活动、自伤、未成年人和个人敏感信息。

真实图片可能包含高风险内容；AI 生成图片也可能完全安全。任何单一模型结论都不能替代另一条审核链。

## 2. 样本矩阵

| 真实性参考 | 内容安全参考 | 代表样本 | 评测目的 |
|---|---|---|---|
| AI 生成 | 安全 | 虚构主持人、普通人像 | 验证真实性召回，防止把“AI 生成”错误等同于“违规” |
| AI 生成 | 有风险 | 钓鱼页、儿童行程、自伤预警、营销违规 | 验证两条链能同时给出独立证据 |
| 真实/公开许可 | 安全 | Open Images 普通场景 | 测量内容安全误报与真实性误报 |
| 真实/公开许可 | 有风险 | Open Images 武器类、合规来源的集会/边界场景 | 测量真实风险内容召回 |
| 来源已签名 | 任意 | c2pa-rs 公开夹具 | 证明“来源有效”不等于“内容真实或安全” |
| 来源未知 | 任意 | 用户授权试标样本 | 验证人工复核与审计闭环，不公开原图 |

## 4. 公开数据来源规则

- Open Images V7 可按类别和图片 ID 下载，元数据包含原始来源、作者和每张图的许可证。纳入前必须逐图核验 `License` 与落地页，并在证据中保存图片 ID、来源 URL、作者、许可证和 SHA-256。官方入口：<https://storage.googleapis.com/openimages/web/index.html>。
- Visual Redactions/VISPR 提供视觉隐私标注研究代码，代码仓库为 Apache-2.0；图片数据的再分发权不能由代码许可证推导。数据条款未人工确认前只作为候选，不把原图放入 Git、驾驶舱或飞书。项目：<https://github.com/tribhuvanesh/visual_redactions>。
- 成人、暴力血腥、自伤和未成年人样本优先使用非血腥、非露骨、虚构的受控合成图。若使用研究数据集，仅在访问协议允许的本地隔离目录评测，飞书和大屏只放打码缩略图。
- 搜索引擎图片、来源不明转载、无许可证截图不得进入基准库。

## 5. 验收字段

每个样本必须记录：`sample_id`、参考标签、来源类型、原始 URL/生成模型、许可、提示词摘要、原图 SHA-256、公开缩略图 SHA-256、模型、策略版本、延迟、完整分类输出、人工标签和误报/漏报解释。人工标签只能由真实审核员提交。
